## 🛒 Task 1: E-Commerce Store

A full-stack e-commerce website built with Node.js, Express, and EJS.

**Features:**
- User registration, login, and session management
- Secure password hashing using bcrypt
- Browse and view product details
- Add/update/remove items from cart
- Checkout system with order confirmation
- User-specific order history
- SQLite database for users, products, and orders

**Tech Stack:** Node.js, Express.js, EJS, SQLite, better-sqlite3

📂 [View Task 1](./task1-ecommercestore)

## ⚙️ How to Run Any Task Locally

1. Navigate into the task folder, e.g.:
   ```bash
   cd task1-ecommercestore
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the server:
   ```bash
   node server.js
   ```
4. Open your browser at `http://localhost:3000` (or the port specified in `server.js`)
